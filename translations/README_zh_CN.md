## 欢迎，矿工！⛏️ 欢迎来到 **MinersWorldCoin**，一种以“人人都能公平、便捷地挖矿”为目标的加密货币。

MinersWorldCoin 不是快速致富的捷径，不是 ICO 敛财的工具，也不是 ASIC 矿机的乐园。 MinersWorldCoin **没有 ICO，没有预挖矿，也没有任何隐藏优势**——只有基于 CPU 的公平挖矿。

无论您使用的是老式台式机、家用服务器还是现代工作站，**您的 CPU 就是您的镐头**。只要您有计算能力，就能挖矿。这就是 MinersWorldCoin 的基石：通过便捷性实现去中心化。

MinersWorldCoin Core 是该网络的参考实现，提供了一个由 **yespowerMWC** 算法保护的 **Layer-1 区块链**——旨在抵御 ASIC 矿机的垄断，并确保挖矿过程公平、分布式且由社区驱动。

有关 MinersWorldCoin 网络默认手续费的信息，请参阅[手续费建议](doc/fee-recommendation.md)。

**网站：** [MinersWorldCoin](https://www.minersworld.org/)

## MinersWorldCoin 的挖矿世界 🌐

MinersWorldCoin 的构建基于一个简单的原则：

**一个 ​​CPU，一个声音。**

无需专用硬件。没有内部优势。没有中心化发行。每个人都以相同的方式创建代币——通过为网络贡献实际的计算工作。

**主要特性：**

- **仅 CPU 挖矿** — 任何拥有处理器的人都可以参与

- **无 ASIC 挖矿** — 防止工业中心化

- **无 ICO** — 无预售供应

- **无预挖矿** — 从第一个区块开始公平启动

- **去中心化设计** — 算力始终掌握在矿工手中

## 为真正的矿工打造 ⚙️

MinersWorldCoin 的灵感源自加密货币的早期——那时挖矿**人人**都可以在家进行。它秉承着与狗狗币相似的精神，但更加注重**CPU 公平性**。

这里没有 GPU 竞相抢占先机，也没有 ASIC 矿场挤压小型矿工的生存空间。只要你贡献 CPU 算力，你就是在为区块链的安全做出贡献——而且你还能公平地获得应得的份额。

在这里，挖矿的关键不在于谁的矿机最大。

而在于参与。

## 使用指南 🧭

要开始挖矿或运行节点，请按照[安装指南](INSTALL.md)和[入门教程](doc/getting-started.md)进行操作。

MinersWorldCoin Core 包含一个功能齐全、文档清晰的**JSON-RPC API**。使用方法：

`minersworldcoin-cli help`

如需更深入的技术参考，请参考[比特币核心 RPC 文档](https://developer.bitcoin.org/reference/rpc/)，因为 MinersWorldCoin 遵循相同的基础标准。

### 版本控制和分支 🧱

版本控制遵循 **主版本号.次版本号.补丁版本号** 的格式。

分支结构：

- **master** — 最新稳定版本

- **maintenance** — 维护中的先前版本

- **development** — 活跃开发和新功能

贡献流程：

- **新功能** → `development`

- **错误修复** → `maintenance`
